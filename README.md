Solar Flare is a responsive 2D arcade space survival and harvesting game built with pure HTML5 Canvas and ES modules (no external frameworks or network dependencies). Steer your orbital interceptor, evade coronal solar flare anomalies, harvest quantum plasma cores, and achieve high score combos across escalating difficulty sectors.

## Play Locally

```sh
node serve.ts
```
Then open http://localhost:8080 in desktop Chrome.
